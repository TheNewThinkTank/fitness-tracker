# Skill Routing

When a request matches an available skill, load and follow that skill using the
host's supported skill-loading mechanism. Use only skills available in the
current session. Answer quick questions and small scoped edits directly.

- Product ideas and brainstorming: office-hours.
- Strategy and scope: plan-ceo-review.
- Architecture: plan-eng-review.
- Design: design-consultation or plan-design-review.
- Full plan review: autoplan.
- Bugs and errors: investigate.
- Browser and API testing: qa or qa-only.
- Code review: review.
- Visual polish: design-review.
- Shipping and deployment: ship or land-and-deploy, only when requested.
- Save or restore working context: context-save or context-restore.
- Executable specifications: spec.

Do not create commits, branches, or deployments unless the user requests them.
